# My First Program

A beginner HTML project that brings together several linked pages to practice basic website structure and navigation.

## What It Contains

- A main page with introductory HTML content
- Navigation links between multiple pages
- Home, dashboard, contact, and profile pages
- A CSS directory for styling assets

## Pages

- `index.html` — Main entry page
- `home.html` — Home page
- `dashboard.html` — Dashboard page
- `contact.html` — Contact page
- `profile.html` — Profile page

## Technologies

- HTML
- CSS

## Running Locally

No build tools or dependencies are required.

1. Clone the repository.
2. Open `index.html` in a web browser.
3. Use the navigation links to move between the pages.

## Project Purpose

This project is an early web-development exercise focused on HTML structure, page linking, and organizing a simple multi-page website.
